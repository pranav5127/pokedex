# Pokedex

A minimal Pokedex app built with Expo and TypeScript. Browse Pokémon and view details with a small, easy-to-read codebase.

## Features
- Browse a list of Pokémon
- View Pokémon details (stats, abilities, sprites)
- Small, focused codebase for learning and experimentation

## Prerequisites
- Node.js (LTS recommended)
- Yarn or npm
- Expo CLI (optional) — you can use `npx expo` if you don't want to install globally

#### Run on a platform:

   - Android: `npm run android`
   - iOS: `npm run ios`
   - Web: `npm run web`
